# Deep Picard Regression for Games with Private Information

Research code for computing Nash equilibria of stochastic differential games in which each player observes
different information. The method is described in `notes/method.tex`.

## Overview

Player $i$ chooses a control $u^i$ adapted to the filtration $\mathcal{F}^i$ generated by its own observations.
In the quadratic case, the first order condition of each player is

$$
u^i_t = \frac{1}{2 a_i} \, \mathbb{E}\big[ \Lambda^i_t \,\big|\, \mathcal{F}^i_t \big],
$$

where $\Lambda^i_t$ depends on the future state and on the controls of all players. The open-loop Nash equilibrium
is the fixed point $u = \Psi(u)$ of the operator defined by the right-hand side, computed by the damped Picard
iteration

$$
u^{(k+1)} = (1 - \rho) \, u^{(k)} + \rho \, \Psi\big(u^{(k)}\big).
$$

Each conditional expectation is approximated by a network of the player's own observed path, fitted by minimizing
a mean squared error over simulated paths. No filter is computed. A GRU takes the increments of the observations,
rescaled by $\sqrt{\Delta t}$, as input and returns a summary $h_j$ of the observed path up to $t_j$. A feedforward
network maps $(t_j, O^i_{t_j}, h_j)$ to $u^i_{t_j}$.

At each iteration, the game is simulated once with the controls of all players fixed. The target of player $i$ is

$$
\frac{\Lambda^i_{t_j}}{2 a_i} = u^i_{t_j} + \frac{G^i_j}{2 a_i \, \Delta t},
$$

where $G^i_j$ is the derivative of the realised reward of player $i$ with respect to $u^i_{t_j}$, computed by
automatic differentiation. The next iterate of player $i$ minimizes a mean squared error against
$(1 - \rho) \, u^i + \rho \, \Lambda^i / (2 a_i)$. A martingale control variate is subtracted from the target to
reduce its variance. The validation controls are averaged over the later iterations.

## Examples

Each example has an exact solution of the discretised game, used only to validate the method.

* **Two traders with private signals.** Each trader observes a private Ornstein–Uhlenbeck signal and a common
  price that both traders move. The exact equilibrium is computed among strategies linear in the observed
  path, which contain it in this Gaussian game.
* **Two traders with private Markov-chain signals.** The filter is nonlinear. Exact solution at $\lambda = 0$.
* **Broker and informed trader**, without transient impact. The broker's information is contained in the trader's.
* **Major and minor player**, both partially observed; neither player's information contains the other's.

## Layout

```
src/partial_info_games/
    solver.py             damped Picard iteration, first order condition check
    control.py            the network of each player
    control_variate.py    martingale control variate of the targets
    utils.py              device, validation paths, errors
    plotting.py           plot style and figures
    games/                the game interface (base.py) and one module per game with its exact solution
notebooks/                one notebook per example, and the results of the study
experiments/              runs of the study, exact references, checks, cluster scripts
notes/                    method note, audit, results log
```

## Running the Study

```bash
cd experiments
python references.py              # exact references of the two-trader game (committed)
python runs.py budget --dry-run   # list the runs of a stage
python runs.py budget             # run them; finished runs are skipped
```

On Narval, each stage runs as a job array with one GPU per run:

```bash
cd experiments/cluster
./submit.sh budget
```

The stages are `budget`, `seeds`, `control_variate`, `damping` and `coupling`.
`notebooks/results.ipynb` reads the saved runs from `experiments/results/`.
